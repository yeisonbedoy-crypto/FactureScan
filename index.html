Conectar con Google Sheets vía SheetDB — 3 pasos
1
Prepara tu hoja de Google Sheets
Ve a sheets.new y crea una hoja nueva.
En la primera fila añade estas cabeceras exactamente así (una por columna, de A a P):
A · fecha_escaneo B · proveedor C · nif_proveedor D · numero_factura E · fecha F · cliente G · nif_cliente H · concepto I · base_imponible J · tipo_impuesto K · porcentaje_impuesto L · cuota_impuesto M · total N · moneda O · forma_pago P · observaciones Q · tipo_contable
Copia el texto, pégalo en la celda A1 de tu Sheets y usa Datos → Dividir texto en columnas (separador: tabulación). O escríbelos manualmente uno a uno.
2
Pega el script en Apps Script
En tu hoja de Sheets ve a Extensiones → Apps Script.
Borra todo el código existente y pega este (usa doGet, no doPost):
function doGet(e) { try { var ss = SpreadsheetApp.getActiveSpreadsheet(); var sheet = ss.getActiveSheet(); var cb = e.parameter.callback || ''; // Auto-headers si la hoja está vacía if (sheet.getLastRow() === 0) { sheet.appendRow([ "fecha_escaneo","proveedor","nif_proveedor", "numero_factura","fecha","cliente","nif_cliente", "concepto","base_imponible","tipo_impuesto", "porcentaje_impuesto","cuota_impuesto", "total","moneda","forma_pago","observaciones","tipo_contable" ]); } // Normaliza: elimina todo lo que no sea alfanumérico para comparar function norm(s) { return String(s || '').replace(/[^a-zA-Z0-9]/g, '').toLowerCase(); } // ── DUPLICATE CHECK: solo por numero_factura (columna D) normalizado ── var numFacturaNorm = norm(e.parameter.numero_factura); if (numFacturaNorm && sheet.getLastRow() > 1) { var colD = sheet.getRange(2, 4, sheet.getLastRow() - 1, 1).getValues(); for (var i = 0; i < colD.length; i++) { if (norm(colD[i][0]) === numFacturaNorm) { var dupJson = JSON.stringify({status:"error", msg:"DUPLICATE"}); var dupOut = cb ? cb + '(' + dupJson + ')' : dupJson; return ContentService .createTextOutput(dupOut) .setMimeType(cb ? ContentService.MimeType.JAVASCRIPT : ContentService.MimeType.JSON); } } } // Convierte texto de importe a número (maneja . y , como separadores) function toNum(s) { if (!s || s === '') return ''; var clean = String(s).trim(); if (clean.indexOf(',') > -1 && clean.indexOf('.') > -1) { if (clean.lastIndexOf(',') > clean.lastIndexOf('.')) { clean = clean.replace(/\./g,'').replace(',','.'); } else { clean = clean.replace(/,/g,''); } } else { clean = clean.replace(',','.'); } var n = parseFloat(clean); return isNaN(n) ? s : n; } var p = e.parameter; sheet.appendRow([ p.fecha_escaneo || new Date().toLocaleString("es-ES"), p.proveedor || "", p.nif_proveedor || "", p.numero_factura || "", p.fecha || "", p.cliente || "", p.nif_cliente || "", p.concepto || "", toNum(p.base_imponible), p.tipo_impuesto || "", toNum(p.porcentaje_impuesto), toNum(p.cuota_impuesto), toNum(p.total), p.moneda || "EUR", p.forma_pago || "", p.observaciones || "", p.tipo_contable || "" ]); var json = JSON.stringify({status:"ok"}); var out = cb ? cb + '(' + json + ')' : json; return ContentService .createTextOutput(out) .setMimeType(cb ? ContentService.MimeType.JAVASCRIPT : ContentService.MimeType.JSON); } catch(err) { var json = JSON.stringify({status:"error", msg:err.message}); var out = (e.parameter.callback || '') + '(' + json + ')'; return ContentService .createTextOutput(out) .setMimeType(ContentService.MimeType.JAVASCRIPT); } }
Este script convierte tu hoja en una API que acepta datos. Es gratuito y sin límites — forma parte de tu cuenta de Google.
3
Publica el script y pega la URL aquí
En la ventana de Apps Script:
1. Pulsa Implementar → Nueva implementación
2. Haz clic en el icono ⚙ junto a "Tipo" → selecciona Aplicación web
3. En "Ejecutar como" selecciona Yo (tu email)
4. En "Quién tiene acceso" selecciona Cualquier usuario
5. Pulsa Implementar
6. Si pide autorización → Revisar permisos → elige tu cuenta → "Configuración avanzada" → "Ir al proyecto" → Permitir
7. Copia la URL de la aplicación web que aparece (empieza por https://script.google.com/macros/s/...)
⚠ Importante: cada vez que modifiques el script debes crear una nueva implementación para que los cambios surtan efecto.
📌 Nota importante sobre permisos
Al autorizar el script, Google puede mostrar un aviso de "Google no ha verificado esta app". Es completamente normal para scripts propios.

Haz clic en "Configuración avanzada" → "Ir al proyecto (no seguro)" → Permitir.

El script solo tiene acceso a tu hoja de cálculo y no envía datos a ningún sitio externo.
📐 Fórmulas para totales automáticos en Sheets
Pega estas fórmulas en una celda vacía de tu hoja (por ejemplo columna S) para ver totales actualizados automáticamente.
Total gastos con IVA/IGIC
=SUMIF(Q:Q,"IVA/IGIC",M:M)
Total gastos exentos
=SUMIF(Q:Q,"EXENTA",M:M)
Total general de gastos
=SUM(M2:M)
Total IVA/IGIC a deducir
=SUM(L2:L)
Recuento de facturas
=COUNTA(D2:D)
💡 Consejo: Crea una segunda pestaña en tu Sheets llamada "Resumen" y pon ahí estas fórmulas apuntando a la hoja de datos para tener un panel separado.
