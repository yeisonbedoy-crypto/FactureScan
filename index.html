Conectar con Google Sheets vía SheetDB — 3 pasos
1
Prepara tu hoja de Google Sheets
Ve a sheets.new y crea una hoja nueva.
En la primera fila añade estas cabeceras exactamente así (una por columna, de A a P):
A · fecha_escaneo B · fecha C · numero_factura D · proveedor E · nif_proveedor F · concepto G · base_imponible H · tipo_impuesto I · porcentaje_impuesto J · cuota_impuesto K · total L · moneda M · tipo_contable N · forma_pago O · cliente P · nif_cliente Q · observaciones
Copia el texto, pégalo en la celda A1 de tu Sheets y usa Datos → Dividir texto en columnas (separador: tabulación). O escríbelos manualmente uno a uno.
2
Pega el script en Apps Script
En tu hoja de Sheets ve a Extensiones → Apps Script.
Borra todo el código existente y pega este (usa doGet, no doPost):
function doGet(e) { try { var ss = SpreadsheetApp.getActiveSpreadsheet(); var sheet = ss.getActiveSheet(); var cb = e.parameter.callback || ''; // Auto-headers si la hoja está vacía — nuevo orden if (sheet.getLastRow() === 0) { sheet.appendRow([ "fecha_escaneo","fecha","numero_factura", "proveedor","nif_proveedor","concepto", "base_imponible","tipo_impuesto","porcentaje_impuesto", "cuota_impuesto","total","moneda", "tipo_contable","forma_pago","cliente", "nif_cliente","observaciones" ]); } // Normaliza: elimina todo lo que no sea alfanumérico function norm(s) { return String(s || '').replace(/[^a-zA-Z0-9]/g, '').toLowerCase(); } // ── DUPLICATE CHECK: numero_factura en Columna C (índice 3) ── var numFacturaNorm = norm(e.parameter.numero_factura); if (numFacturaNorm && sheet.getLastRow() > 1) { var colC = sheet.getRange(2, 3, sheet.getLastRow() - 1, 1).getValues(); for (var i = 0; i < colC.length; i++) { if (norm(colC[i][0]) === numFacturaNorm) { var dupJson = JSON.stringify({status:"error", msg:"DUPLICATE"}); var dupOut = cb ? cb + '(' + dupJson + ')' : dupJson; return ContentService .createTextOutput(dupOut) .setMimeType(cb ? ContentService.MimeType.JAVASCRIPT : ContentService.MimeType.JSON); } } } // Convierte texto de importe a número (maneja . y , como separadores) function toNum(s) { if (!s || s === '') return ''; var clean = String(s).trim(); if (clean.indexOf(',') > -1 && clean.indexOf('.') > -1) { if (clean.lastIndexOf(',') > clean.lastIndexOf('.')) { clean = clean.replace(/\./g,'').replace(',','.'); } else { clean = clean.replace(/,/g,''); } } else { clean = clean.replace(',','.'); } var n = parseFloat(clean); return isNaN(n) ? s : n; } var p = e.parameter; // appendRow en el nuevo orden: A-Q sheet.appendRow([ p.fecha_escaneo || new Date().toLocaleString("es-ES"), // A p.fecha || "", // B p.numero_factura || "", // C p.proveedor || "", // D p.nif_proveedor || "", // E p.concepto || "", // F toNum(p.base_imponible), // G p.tipo_impuesto || "", // H toNum(p.porcentaje_impuesto), // I toNum(p.cuota_impuesto), // J toNum(p.total), // K p.moneda || "EUR", // L p.tipo_contable || "", // M p.forma_pago || "", // N p.cliente || "", // O p.nif_cliente || "", // P p.observaciones || "" // Q ]); var json = JSON.stringify({status:"ok"}); var out = cb ? cb + '(' + json + ')' : json; return ContentService .createTextOutput(out) .setMimeType(cb ? ContentService.MimeType.JAVASCRIPT : ContentService.MimeType.JSON); } catch(err) { var json = JSON.stringify({status:"error", msg:err.message}); var out = (e.parameter.callback || '') + '(' + json + ')'; return ContentService .createTextOutput(out) .setMimeType(ContentService.MimeType.JAVASCRIPT); } }
Este script convierte tu hoja en una API que acepta datos. Es gratuito y sin límites — forma parte de tu cuenta de Google.
3
Publica el script y pega la URL aquí
En la ventana de Apps Script:
1. Pulsa Implementar → Nueva implementación
2. Haz clic en el icono ⚙ junto a "Tipo" → selecciona Aplicación web
3. En "Ejecutar como" selecciona Yo (tu email)
4. En "Quién tiene acceso" selecciona Cualquier usuario
5. Pulsa Implementar
6. Si pide autorización → Revisar permisos → elige tu cuenta → "Configuración avanzada" → "Ir al proyecto" → Permitir
7. Copia la URL de la aplicación web que aparece (empieza por https://script.google.com/macros/s/...)
⚠ Importante: cada vez que modifiques el script debes crear una nueva implementación para que los cambios surtan efecto.
📌 Nota importante sobre permisos
Al autorizar el script, Google puede mostrar un aviso de "Google no ha verificado esta app". Es completamente normal para scripts propios.

Haz clic en "Configuración avanzada" → "Ir al proyecto (no seguro)" → Permitir.

El script solo tiene acceso a tu hoja de cálculo y no envía datos a ningún sitio externo.
📐 Fórmulas para totales automáticos en Sheets
Pega estas fórmulas en una celda vacía de tu hoja (por ejemplo columna S) para ver totales actualizados automáticamente.
Total gastos con IVA/IGIC
=SUMIF(M:M,"IVA/IGIC",K:K)
Total gastos exentos
=SUMIF(M:M,"EXENTA",K:K)
Total general de gastos
=SUM(K2:K)
Total IVA/IGIC a deducir
=SUM(J2:J)
Recuento de facturas
=COUNTA(C2:C)
💡 Consejo: Crea una segunda pestaña en tu Sheets llamada "Resumen" y pon ahí estas fórmulas apuntando a la hoja de datos para tener un panel separado.
